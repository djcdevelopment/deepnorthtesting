# Infographic Sources & Visual Summaries

Each `.md` file in this directory is a self-contained source for **one visual infographic**. They are written with tight structure, comparative data tables, and strong thesis statements optimized for **NotebookLM's Infographic generator** or human design pipelines.

---

## How to Generate with NotebookLM

1. Open [NotebookLM](https://notebooklm.google.com/).
2. Create a new notebook (e.g., *"Valheim Profile Engine - Infographics"*).
3. Add the individual `.md` file as a source (one per infographic keeps focus high).
4. Click **Generate → Infographic**.
5. Export the resulting visual card or summary for documentation, Discord announcements, or Nexus Mods release pages.
